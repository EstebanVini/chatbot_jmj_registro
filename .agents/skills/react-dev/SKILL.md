# React Development Skill

Use this skill when building or modifying React applications.

## Guidelines

1. **Functional Components**: Use functional components and React Hooks exclusively. Avoid class components unless working with legacy code.
2. **State Management**: Use appropriate state management (e.g., `useState`, `useReducer`, or Context API) based on the scope of the state.
3. **Performance Optimization**: Use `useMemo` and `useCallback` to prevent unnecessary re-renders when passing props to child components.
4. **Component Structure**: Keep components small and focused. One component per file.
5. **Styling**: Prefer modular styling (CSS Modules, Styled Components, or Tailwind CSS) to avoid global scope pollution.
6. **Accessibility (a11y)**: Ensure components are accessible (e.g., proper ARIA attributes, semantic HTML, keyboard navigation).
7. **Typescript with React**: Define strict interfaces for component Props.
