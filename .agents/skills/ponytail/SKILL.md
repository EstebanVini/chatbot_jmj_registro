# Ponytail - Code Quality Skill

The `ponytail` skill is designed to automatically review and improve the quality of code, ensuring it meets strict standards for readability, maintainability, and reliability.

## Guidelines

1. **Strict Typing**: Always ensure TypeScript code has explicit and accurate types. Avoid `any`.
2. **Modularity**: Break down large functions and components into smaller, reusable pieces.
3. **Naming Conventions**: Use clear, descriptive names for variables, functions, and classes. Follow camelCase for variables/functions and PascalCase for React components and classes.
4. **Error Handling**: Implement robust error handling using try-catch blocks and provide meaningful error messages.
5. **Code Comments & Documentation**: Write JSDoc comments for complex logic and public APIs. Keep comments up-to-date with code changes.
6. **Testing**: Write unit tests for business logic and utility functions.
7. **Clean Code**: Follow DRY (Don't Repeat Yourself) and KISS (Keep It Simple, Stupid) principles.

## Workflow

When asked to review code or apply the ponytail skill:
- Analyze the code for type safety, complexity, and readability.
- Suggest and apply refactoring to improve structure.
- Add necessary comments and documentation.
- Ensure proper error handling is in place.
